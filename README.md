Sistema de Controle de Frequência - Nível Expert
Este é um sistema web leve e eficiente, desenvolvido para o acompanhamento diário de frequência da equipe de atendimento/telemarketing. O projeto foi desenhado para ser prático, rápido e de fácil utilização pelo supervisor, permitindo o gerenciamento em tempo real de assiduidade e pontualidade.

🚀 Funcionalidades Principais
Dashboard de KPIs: Acompanhamento visual imediato do total de operadores, presentes, atrasos e índices de absenteísmo.

Gestão de Equipe: Adição e remoção dinâmica de operadores.

Controle de Pontualidade: Registro de status (No horário / Atrasado) com campo de horário de login.

Frequência: Marcação rápida de presença ou falta (justificada/injustificada).

Modo Escuro (Dark Mode): Alternância de interface para maior conforto visual.

Exportação de Dados: Geração de arquivos CSV para relatórios em Excel/Planilhas.

Impressão Otimizada: Formatação pronta para exportação em PDF ou impressão física, incluindo espaço para assinatura.

Persistência de Dados: O sistema salva automaticamente sua lista de operadores diretamente no navegador (via LocalStorage).

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica do projeto.

CSS3: Estilização responsiva e suporte a temas (Light/Dark).

JavaScript (Vanilla): Lógica de manipulação de tabela, cálculos de KPIs e persistência de dados.

📋 Como Utilizar
Acesso: Abra o arquivo index.html em qualquer navegador moderno (Chrome, Edge, Firefox).

Configuração: Preencha a data e o nome do supervisor nos campos do cabeçalho.

Gerenciamento:

Clique em "👥 Gerenciar Lista" para adicionar ou remover nomes da sua equipe.

A lista será salva automaticamente no seu navegador.

Marcação:

Preencha a matrícula e selecione o status de pontualidade e frequência para cada colaborador.

O sistema calculará automaticamente os indicadores no painel superior.

Relatórios:

Após o preenchimento, utilize o botão "📥 Exportar" para salvar os dados em CSV ou "🖨️ Gerar PDF" para imprimir o relatório diário.

💡 Observações Importantes
Privacidade dos Dados: Como o projeto utiliza localStorage, os dados da sua lista de operadores ficam armazenados localmente no computador/navegador que você está usando. Se você limpar o histórico do navegador ou utilizar um computador diferente, a lista de operadores precisará ser inserida novamente.

Segurança: Caso utilize este projeto em um ambiente público, certifique-se de realizar o backup da sua lista de nomes em um arquivo à parte.
